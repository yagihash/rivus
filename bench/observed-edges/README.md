# 観測した呼び出しとの照合(Go)

設計は [../../docs/DESIGN-observed-calls.md](../../docs/DESIGN-observed-calls.md)。**CI では実行しない**。zoo の Go を実行し、実際に起きた呼び出しのうち、`rivus index` のグラフにないものを出す。

```sh
make observed-edges-go            # 数秒。ARGS=-v で、過大の表の行も出す。作業は一時のディレクトリ(終わると消える)
```

## 何をするか

1. `bench/zoo-go` を**コピー**する(元の木は変えない)。
2. コピーの `cells/` の全部の関数と関数リテラルの先頭に `rvobs.Enter()` を差す(`go/ast` で場所を見つけ、**文字として挿入**する。行番号は 1 つも動かない)。`rvobs`(記録の小さいパッケージ)は、この道具が持っていて、コピーに書く。
3. コピーが `go vet` を通ることを確認し、`-gcflags=all=-l` でビルドして実行する。`Enter` は `runtime.Callers` で、入った関数と呼び出し元(関数名、ファイル、行)を記録する。インライン展開すると入れ子のクロージャの名前が変わる(`f.func1.1` と `f.func1.func1`)ので、展開は切る。
4. 別のコピー(差し込む前)に `rivus index -graph`(一時のファイル)をかけ、記録した名前を fid に直して(下)、グラフと比べる。

## 名前の合わせ方(`names.go`)

| 実行時の名前 | fid |
|---|---|
| `pkg.F` | `pkg.F` |
| `pkg.T.M` | `(pkg.T).M`(値レシーバー。ポインタ形 `(*pkg.T).M` と同じ関数として比べる) |
| `pkg.(*T).M` | `(*pkg.T).M` |
| `pkg.F.func1`、`.func1.2`、`.func1.func1` | `pkg.F$1`、`pkg.F$1$2` |
| `pkg.init.0` | `pkg.init#1` |
| `pkg.G[...]` | `pkg.G[T]`(型引数の並びは比べない) |

位置は、呼び出し元の関数の fid と**行**で `callsites` を引く(桁は取れない)。同じ行に呼び出し点が複数あれば、そのどれかが呼び出し先へのエッジを持てば `ok`。

## 出力の表

| 区分 | 意味 |
|---|---|
| `ok` | グラフにある。メソッド値の中継(`m$bound`)は 1 段たどる |
| `no_edge` | 呼び出し点はあるが、その呼び出し先へのエッジがない(**取りこぼしの候補**) |
| `no_callsite` | その関数のその行に、グラフの呼び出し点がない |
| `id_unmapped` | 名前が、グラフの関数に写せない(観測の側の誤りか、名前の規則の不足) |
| `outside` | 比べない。`harness`(cases を動かす側)、`other_module`(標準ライブラリなどが cells を呼ぶ。入口しか見えない)、`go_stmt`(`go` 文で始めた関数。呼び出し元が分からない)、`no_position`(グラフに行がない呼び出し点。[#197](../../docs/issues/197-go-range-over-func-call-has-no-position.md)) |

**過大**は別の表で、情報だけ: 呼び出し点のうち、候補(`ncand`)が 2 以上で、観測で 1 回でも見えたもの。「候補 N 件、観測 M 件」。見えなかった候補は、誤りとは限らない(各ケースは 1 回ずつ)。

## 見えないもの(限界)

- リフレクションと生成コードは照合の外。
- `defer` で呼ばれる関数の呼び出し元の行は、`defer` の文ではなく、関数の閉じ括弧の行になる。
- 標準ライブラリが呼ぶコールバックは、呼び出し元が標準ライブラリなので `other_module`。
- 実行されなかった枝は何も言えない。
- 第三者のコードは実行しない(隔離が先。設計書 7 節)。

| | |
|---|---|
