# The rows of the built-in model that no call in the zoo (bench/zoo-*) or in the curated targets (bench/*-curated) hits.
# TestBuiltinRowsAreHitByTheZoo (cmd/rivus) reads it. The form of a line is "lang symbol | reason".
#
# A row that is not here has to be hit: a new row without a cell of the zoo that calls it fails the test. A line here is
# taken out as soon as the row is hit (the test says so), and a line for a row that does not exist is an error.
# What may stay here for good is an API that a run cannot check (it needs a server, a device, a network): docs/MODELING.md.
#
# Three reasons are used:
#   dependency  the library is not the standard one, and the zoo has no dependency but the packages of the Dart team (path).
#               A row of it is checked against the IR of real code (bench/parity), not by a call of the zoo.
#   debt        the standard library: no cell calls it yet. These lines only go down: a cell that calls the API (a case
#               of the zoo, or a function of bench/*-curated that calls it) takes a line out; none is to be added for a
#               new row.
#   spelling    the other spelling of an API that has its row with the name the extractor writes; kept for the version
#               of the library or the extractor that writes this one.
