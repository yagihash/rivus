The cells of the Go zoo that the Dart zoo has no counterpart of, with the reason (the Go zoo's other cells that Dart does not have yet are stage 3).
Read by TestZooDart (the parity line). Two marks (docs/DESIGN-zoo.md, 4.2.5): @na(F/<family>/<shape>: reason) is a form that Dart does not have at all;
@todo(F/<family>/<shape>: PARITY: reason) is a form that Dart can have and the cell is not written yet (a Go cell with no mark is counted as @todo too).

@na(F/dyn/iface-ptr-recv-read: Go's pointer receiver of a method that an interface holds; a Dart object is always a reference)
@na(F/dyn/iface-ptr-recv-write: the same)
@na(F/dyn/iface-write-passed: a Go pointer held in an io.Writer interface value; a Dart object is always a reference)
@na(F/dyn/generics-ptr: a Go pointer type argument; Dart's generics are reified and have no pointer receivers)
@na(F/clos/range-func: Go's range over a function (for v := range seq, the iterator calls yield); Dart's for-in drives Iterator.moveNext, and no loop calls the body as a closure (Iterable.forEach(f) takes a closure the other way round, a different cell))
@na(F/cont/ptr-value-copy: a Go struct value taken by a comma-ok assertion or a range is a copy, and a field written in the copy is not written back; a Dart object is always a reference and has no such copy)
@na(F/conv/builtin-minmax: Go's built-in min and max of strings; Dart's min and max (dart:math) take numbers only, so there is no form that gives one of the string arguments)
@na(F/conv/unsafe-string: Go's unsafe.String and unsafe.Slice, which make a value of the bytes that a pointer holds; Dart has no pointer to a byte and no such form)
@na(F/net-http/request-literal: Dart's http.Request has a constructor only, so there is no difference between a literal and NewRequest; the send path is measured by dart/http-ioclient-send)
@todo(F/call/regexp-replace: PARITY: Dart で未測定: RegExp の replaceAllMapped、replaceAll、replaceFirst で書ける)
@todo(F/cont/ptr-index-slice: PARITY: Dart で未測定: List の要素を変数に取り、そのフィールドに書いて、List から読み直す形で書ける)
@todo(F/cont/ptr-range-map: PARITY: Dart で未測定: Map の values を for-in で取り、そのフィールドに書いて、Map から読み直す形で書ける)
@todo(F/cont/ptr-type-switch: PARITY: Dart で未測定: Dart 3 の switch のパターン(case Box p)で書ける)
@todo(F/conv/char-range-append: PARITY: Dart で未測定: s.runes を for-in で読み、List<int> に add して String.fromCharCodes で戻す形で書ける)
