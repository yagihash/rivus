The cells of the Go zoo that the Dart zoo has no counterpart of, with the reason (the Go zoo's other cells that Dart does not have yet are stage 3).
Read by TestZooDart (the parity line). Two marks (docs/DESIGN-zoo.md, 4.2.5): @na(F/<family>/<shape>: reason) is a form that Dart does not have at all;
@todo(F/<family>/<shape>: PARITY: reason) is a form that Dart can have and the cell is not written yet (a Go cell with no mark is counted as @todo too).

@na(F/dyn/iface-ptr-recv-read: Go's pointer receiver of a method that an interface holds; a Dart object is always a reference)
@na(F/dyn/iface-ptr-recv-write: the same)
@na(F/dyn/iface-write-passed: a Go pointer held in an io.Writer interface value; a Dart object is always a reference)
@na(F/dyn/generics-ptr: a Go pointer type argument; Dart's generics are reified and have no pointer receivers)
