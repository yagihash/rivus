# 127: `-timeout` の超過の残り: 1 つの関数の中と、extractor の段階

課題 #126 で、並列ラウンドの中では期限を見るようにした。残っているもの。

1. **1 つの関数の解析の中**: `-timeout` は、解析している関数の中では見ない。1 つの関数が長い間かかると、その分だけ超える。`-func-timeout`(既定 30 秒)が別にあり、それが上限になる。
2. **extractor の段階の時間**: `-timeout` は解析の段階の上限で、読み込み(extractor、グラフの構築)の時間は含まない。その時間は `stats` に出ない(`-v` の段階の時間にだけ出る)。依存を含む大きいプロジェクトで、全体の時間が `-timeout` を大きく超えて見えるのは、これが原因のことがある。

修正の案: (1) は、`-func-timeout` と `-timeout` の残りの小さいほうを、関数の上限にする。(2) は、段階ごとの時間を `stats` に出す。
