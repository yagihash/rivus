# 170: ラベルを受ける sink がないときと、query の綴りの誤りが、警告されない

- 状態: **open**
- 種類: サイレントな見逃し(利用者の書き間違い。重さ: 中)
- 言語: 全
- ROADMAP の節: 2
- 守るもの: -

Go の実際のプロジェクトでの利用(2026-11-23)から出た要望。次の 2 つで、何も報告されずに、結果が空になる。

1. source のラベルを受ける sink が、ルールにもモデルにもない。
2. `query` の綴りの誤り(存在しない名前)。

どちらも、利用者は、「見つからなかった」のか「書き間違えた」のか、出力から区別できない。

直す方向: 一致するものがなかったルールの要素を、警告として出力に残す。
