# 158: source に、「外部のサービスが運んだ、ほかの利用者の入力」を区別するラベルがない

- 状態: **open**
- 種類: 書式(重さ: 低)
- 言語: 共通(Dart の `github` で分かった)

GitHub のファイルや issue の本文のように、外部のサービスのクライアントが運ぶ、ほかの利用者が書いた入力は、組み込みのモデルでは、既定の `user_input` で source にするしかない。`file_content`(ファイルの読み出し)は、意味が違う。利用者が、HTTP の入力と、サービス経由の入力を区別して、外すことができない。

案: ラベル(例 `service_content`)を足し、`docs/MODELING.md` に、どの値に付けるかの基準(利用者が書いた内容を運ぶ値)を書く。ラベルごとに外せる手段が、今の書式にあるかの確認が先。
