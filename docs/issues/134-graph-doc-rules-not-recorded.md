- 言語: 全
- 見つけた経緯: 利用ガイド(docs/AGENT-GUIDE.md)を書くときに、help とコードを読んで見つかった食い違い。v0.0.4 には入れない。

`graph … -C` に `-rules` を付けないと `fresh: false` になる(`-rules` は記録から使われない)。文書を直すか、`-rules` も記録から使うようにするか。後者は、索引のキーの設計(ルールの内容の扱い)に関わるので、相談役が決める。

## 直した内容

`index` に渡した `-rules` のファイル(絶対パス)を、グラフのファイルのフラグの記録に残し、`graph … -C`(`info` も)で `-rules` を省いたときは、それを使うようにした。記録されたファイルがなくなっている、または内容が変わっているときは、今までと同じく `fresh: false` と `stale_reasons` で報告する。明示した `-rules` は記録より優先する。索引のキー、スキーマは変えていない(古いファイルには記録がなく、これまでどおり)。docs/GRAPH.md と docs/AGENT-GUIDE.md を直した。
