## BENCH-3: `@noisy(N)` は、入れ替わりに気づけない
数だけを見るので、ある誤った流れが消えて別の誤った流れが増えても、同じ N なら通る。Rust の 183 件は案 2(ADR-047)で減るはずの数で、減り方が受け入れの確認になる。
- 方向: 案 2 の前後では、数だけでなく (source のタグ, sink の行) の組の集合をファイルに書き出して比べる(テストに入れなくてよい。差分の分類の材料)

## BENCH-4: `unsupported` と、未収束の関数の数を、採点で見ない
サンプルのテストは `unsupported` が 0 件であることを見るが、curated は見ない。
- 方向: curated でも `unsupported_construct` が 0 件であること(または数の歯止め)を見る
