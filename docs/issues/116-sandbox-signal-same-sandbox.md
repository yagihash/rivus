# #116 シグナルを same-sandbox にする(cargo が子にシグナルを送れるように)

- 状態: **open**(後回しのハードニング。ADR-093)
- 種類: 隔離の仕上げ
- 言語: Rust
- ROADMAP の節: 0
- 守るもの: -
- 補足(ROADMAP の節): 0(Homebrew のインストールの作業の続き)
- 補足(守るもの): まだない(直すときにテストを足す)

## 今の状態

`(deny signal (target others))` と `(target self)` だけだと、cargo が子(rustc、ビルドスクリプト)にシグナルを送れない場面がありうる。

## 終わりの条件

`(allow signal (target same-sandbox))` を足し、利用者のほかのプロセスに `kill -0` が通らないテストが成功したままであること。
