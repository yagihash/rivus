## 問題
`rivus graph` の索引の鍵(キャッシュの同一性)に、次が入っていない。偽のヒット(古い索引を使う)は、サイレントな見逃しになる。
- Dart の extractor 自体のソース
- Rust の上位のワークスペースの `Cargo.lock`
- `-C` の外の path 依存

## 期待と実際
期待: 結果を変えうる入力が変わったら、索引は作り直される。実際: 上の 3 つが変わっても、鍵が同じなら古い索引が使われる。

## 修正の方向
3 つを鍵に入れる(または、入れられないものは、索引に「鍵の外の入力がある」と記録して出力に書く)。
