# #111 bsd.sb の許可の棚卸しと、変わったら落ちるテスト

- 状態: **open**(後回しのハードニング。ADR-093)
- 種類: 隔離の漏れの見落とし
- 言語: Rust
- ROADMAP の節: 0(Homebrew のインストールの作業の続き)
- 守るもの: まだない(直すときにテストを足す)

## 今の状態

プロファイルの許可の大半は、import した Apple の `bsd.sb` から来る(`(allow file-read-metadata)` が全体、など)。OS の版が上がると中身が変わる。

## 終わりの条件

`bsd.sb` の `allow` を全部書き出し、「必要 / 不要なので拒否し直す / 拒否できない」に分けた表を設計に置く。許可の一覧が、前に確かめたものと同じかをテストで(違ったら落ちる)。
