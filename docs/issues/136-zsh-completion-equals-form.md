# 136: zsh の補完で、`-lang=` のように `=` でつなぐ形のとき、値の一覧が出ない

- 種類: 道具(重さ: 低)

- 守るもの: -
- 題: zsh の補完で、`-lang=` のように `=` でつなぐ形のとき、値の一覧が出ない
- 見つけた経緯: `rivus completion zsh`(#155)を、対話的な zsh(`zpty`)で確認したときに見つかった。

`-lang ` のように空白で区切ると値の一覧(`go`、`dart`、`rust`、`auto`)が出るが、`-lang=` の形では一覧が出なかった(`-pass-stats-sort=` は出た)。`_arguments` の指定の形(`-lang=[…]:lang:(…)` と `-lang[…]:…` の違い)と、zsh の `=` の扱いを確認して、両方の形で補完されるようにする。未調査。
