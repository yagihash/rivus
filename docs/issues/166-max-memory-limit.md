# 166: メモリの上限(-max-memory)で、解析を止められない

- 状態: **open**
- 種類: 利用者を止める(重さ: 中)
- 言語: 全
- ROADMAP の節: 3
- 守るもの: -

Go の実際のプロジェクトでの利用(2026-11-23)から出た要望。依存込みの解析は、メモリを大きく使うことがあり、ホストのメモリを使い切る前に、利用者が上限を決めて止められる手段がない(`-timeout` は時間だけ)。

直す方向: `-max-memory` を足し、上限に達したら、止めた理由と、そこまでの結果の範囲を出力に残して終わる(何も報告せずに切らない)。止めたときは、結果が部分的なことを、不確実性として出す。
