# #199 Rust: サンドボックスの cargo の置き場(`rivus-cargo-<ハッシュ>`)が、依存が変わるたびに増え、掃除の仕組みがない

- 状態: **open**
- 種類: 資源(利用者のディスク)
- 言語: Rust
- ROADMAP の節: -
- 守るもの: -

## 何が起きるか

本番の経路(`cmd/rivus/isolate_sandbox_darwin.go` の `extractRustSandboxed`)は、`cargoVolume` で、プロジェクトの依存(`Cargo.lock` と `.cargo/config` の内容のハッシュ)ごとに、`rivus-cargo-<ハッシュ>` という置き場を作る。場所は `~/Library/Application Support/rivus/rust/` の下。

依存が変わるたびに別の置き場ができる。**削除も、合計の上限も、掃除の仕組みもない**。使われなくなった古いものが、利用者のディスクに溜まり続ける。1 つが 1 GB 以上になるものもある。

## 設計との関係

再利用のためのキャッシュなので、置き場が増えること自体は設計どおり。足りないのは、古いものの掃除。uncertainty の課題ではなく、資源の課題。

## 修正の案

- 最後に使った日で消す(例: 一定の日数、使われていないもの)
- 合計の大きさに上限を置き、超えたら古いものから消す
- `rivus` の明示のサブコマンドで、一覧と削除ができるようにする

どれを選ぶかは、相談役が決める。
