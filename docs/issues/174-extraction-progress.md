# 174: Dart: extractor の読み込みが長いとき、何を読んでいるかが見えない

- 状態: **open**
- 種類: 道具(重さ: 中)
- 言語: Dart
- ROADMAP の節: 3
- 守るもの: -

実際のプロジェクト(cocoon の `app_dart`)に、`-C` を誤って親のディレクトリに向けたとき、extractor の読み込みが 700 秒を超えても終わらず、その間、標準エラーに何も出なかった。待っている人には、止まっているのか、進んでいるのか、何を読んでいるのかが分からない。[#167](167-taint-progress.md) は taint の段階の進捗で、こちらはその前の、読み込みの段階。同じ種類の要望。

直す方向: 読み込みの段階で、読んでいるパッケージ(または、読んだファイルの数)を、一定の間隔で標準エラーに出す(出力の JSON は変えない)。待つか止めるかを、利用者が決められるようにする。
