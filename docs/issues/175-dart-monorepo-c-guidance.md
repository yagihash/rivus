# 175: Dart: モノレポで `-C` に何を指すか、README の案内が足りない

- 状態: **open**
- 種類: 道具・ドキュメント(重さ: 中)
- 言語: Dart
- ROADMAP の節: 3
- 守るもの: -

[#287](https://github.com/yagihash/rivus/pull/287) で、`-C` の振る舞いが変わった(`-C` は解析の始まり。読み込みの範囲は、`-allow-deps-under` と依存のつながりで決まる)。そのあと、実際のモノレポ(cocoon)で試すと、`-C` に何を指すかで結果が大きく変わった: アプリのディレクトリ(`app_dart`)に向けて、兄弟のパッケージを `-allow-deps-under` で足すと終わる。リポジトリのルートに向けると、終わらないことがある。`packages` に向けると、別のプロジェクトを解析する。

この PR で README のモノレポの節を、この説明に書き換えた。残り: ルートに向けたときに終わらない原因(読む範囲が広がる理由)を調べる。範囲が広がるとき、標準エラーに知らせる([#174](174-extraction-progress.md) と合わせて)。
