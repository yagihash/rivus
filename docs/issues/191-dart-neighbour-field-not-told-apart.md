# #191 Dart: 同じ 2 段目のノードの下の隣のフィールドが、どの深さでも区別されない

- 状態: open
- 種類: 過検出(構造的)
- 言語: Dart
- ROADMAP の節: 2
- 優先度: 高(Dart が主な言語)
- 守るもの: 精度
- 題: 依存のオブジェクトの、同じ内側のオブジェクトの下の隣のフィールドが、どの深さでも区別されない

## 何が誤って報告されるか

依存のオブジェクトの 3 段目のフィールド C に値を入れ、同じ内側のオブジェクトの隣のフィールド D(定数)を、プロジェクトが sink に渡す形(`o.a.b.c` と `o.a.b.d`)で、Dart は、**深さ 1 から 6 のどれでも** D が報告される。Go は、深さ 3 以上で D を区別する。深さの効果ではない(深さを上げても消えない)。テスト: `cmd/rivus/depth_boundary_dart_test.go`(今日の事実を表にしてある)。

## 原因(未調査)

Go の #179(埋め込み構造体の昇格で、フィールドの区別が失われる。依存のクラスのフィールドが 1 つのセルにまとまる)と同じ原因かどうかは、分かっていない。確かめること: Dart の `field_store` で、`build` が C と D を別のパスに書いているか(IR を見る)。同じ内側のオブジェクトの 2 つのフィールドが 1 つのセルになるのか、書くときにフィールド名が落ちるのか。最小の形に分けて、テスト(`depth_boundary_dart_test.go` に足す)で、どこで区別が失われるかを決める。

## 扱い

#179 の設計メモと一緒に扱う(原因が同じなら、同じ修正)。

## 前提

#190(深さの数え方)とは別。ADR-119。
