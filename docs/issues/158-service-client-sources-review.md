# 158: 既存のサービスのクライアントのモデルを、「その値を誰が書いたか」の基準で見直す

- 状態: **open**
- 種類: モデル(source の見直し。重さ: 中)
- 言語: 全(`dart-gcp`、`go-gcp` など、サービスのクライアントのモデル)
- 基準: [ADR-108](../DECISIONS.md)

ADR-108 は、サービスのクライアントのモデルで、利用者が書いた内容(メッセージの本文、Issue の本文、コメントなど)は source にし、サービスが決める値(ID、時刻、SHA、件数)は source にしない、と決めた。既存のモデルは、この基準で作っていない。

見直す対象の候補: Pub/Sub のメッセージの本文(`PubsubMessage.data` など。利用者が書いた内容)。ほかに、Firestore のドキュメントの値、Storage のオブジェクトの内容など(`stored` と `queue_message` の source は、`docs/GCP-MODELS.md` の方針で、利用者の選択になっている。この課題で、その扱いと合わせて決める)。

進め方: 行ごとに、「誰が書いたか」を表にして、source にする値、しない値、迷う値(コメントに理由)に分ける。source を足すと、既定の検出が増える(誤検出の面で影響が出る)ので、公開のベンチの前後を測る。

`Writer.Write`(保存する内容)に合うカテゴリがない。保存する内容そのものは、読み戻す側の `stored` の扱いと一緒に考える。
