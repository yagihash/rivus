# 課題のファイル

課題は 1 件 1 ファイル。**一覧の表は、手で持たない**。各ファイルの先頭のヘッダから、`make docs-gen` が作る(コミットしない)。課題を足す PR は、課題のファイルを足すだけ。`docs/ISSUES.md` は触らない(衝突しない)。

## 見方

- 一覧: `make docs-gen WHAT=issues`(標準出力。`WHAT` なしは ADR の表も出る)。ファイルに書くなら `make docs-gen WHAT=issues OUT=docs/ISSUES-TABLE.md`(`.gitignore` の対象)。
- 開いているか閉じたかは、ファイルのヘッダの `状態` で決まる。**閉じても、ファイルは動かさない**(`docs/issues/<番号>-*.md` を、zoo の `@ref(#N)`、ゲート、ほかの文書のリンクが指すため)。ヘッダの `状態` を `closed` に変えるだけ。

## 足し方

1. 番号は、`docs/issues/` の最大の番号 + 1(欠番があってよい)。番号がほかの PR と重なったら、`TestIssuesFiles` が落ちる。あとから入る PR が、番号を付け直す。
2. ファイル名は `<番号>-<短い名前>.md`。
3. 1 行目は `# <題>`、その下にヘッダ(次の節)。
4. `make docs-gen` で、行が出ることを確かめる。

## ヘッダの形

`# ` の題の行のすぐ下に、`- <キー>: <値>` の行を並べる(`## ` の見出しより上)。キーは次の 5 つ + 任意の 1 つ。足りないキーは、表では空になる。

| キー | 内容 |
| --- | --- |
| `状態` | `open` / `partial` / `closed` / `deferred` / `wontfix`(`**open**` のように太字でもよい。最初の語が使われる。後ろに説明を書いてよい) |
| `種類` | 失敗の重さに合わせた種類(例: サイレントな見逃し、過検出、道具・ベンチ) |
| `言語` | `Go` / `Dart` / `Rust` / `全` など |
| `ROADMAP の節` | ROADMAP の節の番号。なければ `-` か `0` |
| `守るもの` | 再発を止める zoo のセルかテスト。なければ `-` |
| `題`(任意) | 表に出す題。`# ` の題が長いときだけ書く。なければ `# ` の題(先頭の `#N ` や `N: ` は除く) |

そのほかの行(`- GitHub: ...`、`- 補足(状態): ...`、`- 設計: ...` など)は、表には出ない。

```markdown
# #200 Go: 〜のとき、〜が見逃される

- 状態: **open**
- 種類: サイレントな見逃し
- 言語: Go
- ROADMAP の節: 2
- 守るもの: zoo `F/clos/stored`
```

`TestIssuesFiles`(`cmd/rivus/issues_test.go`)が、番号の一意性、ヘッダ(5 つのキーがあること、`状態` が上の語であること)、生成した表に全部の番号の行があることを確かめる。`TestDocLinks` が、文書の相対リンクが切れていないことを確かめる。

## ファイル名の 2 つの形

| 形 | ファイル名 | 誰が付けるか | 表 |
| --- | --- | --- | --- |
| 番号 | `<番号>-<短い名前>.md`(例 `77-many-closures-to-helper.md`) | 相談役 | `make docs-gen` が出す |
| 名前 | `model-<パッケージ>-<名前>.md`(例 `model-dart-gcloud-pubsub-lookup.md`。英小文字・数字・`-`・`.`・`_`) | モデルを作った PR(番号を取らない) | 出ない。zoo の `@ref(model-...)` からたどれる。あとでまとめて番号にしてよい |

zoo の `@miss` と `@fp` の行(新しいセルの行)の `@ref` は、この 2 つの形で、**ファイルが実際にある**ものを指す(`scripts/zoo-loosened-check.sh` が確かめる)。`@ref(#N)` は `docs/issues/N-*.md`、`@ref(model-...)` は `docs/issues/model-....md`。

## 名前の形のファイルの様式(ゲートが節の存在を確かめる)

```markdown
# <題: 何が、どの条件で>

## 何が見逃されるか(または、何が誤って報告されるか)

## 原因

## 再現するセル

(zoo のセルのパスと、その行の `@miss` / `@fp`)
```

節の見出しは、`## 何が見逃されるか`、`## 原因`、`## 再現するセル` の 3 つ(見出しの行の頭がこのとおりであれば、後ろに語を足してよい)。最初の行は `# ` の題。ほかの節は自由。
