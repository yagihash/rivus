# 157: Dart のジェネリクスのメソッド(`get<T>`)が差分テストで検証できない

- 状態: **open**
- 種類: 道具(重さ: 中)
- 言語: Dart
- ROADMAP の節: 3
- 守るもの: -
- 題: Dart のジェネリクスのメソッド(`get<T>`)が、差分テストで検証できない
- 補足(種類): 道具(検証できない行が、未検証で残る。重さ: 中)
- 補足(言語): Dart(`dio` の `Dio.get<T>` などで分かった。Go のジェネリクスの関数も同じ)

差分テスト(`bench/model-diff`)の生成器は、単純な型の引数の関数のプローブしか作れない。型の引数を持つメソッド(`Dio.get<T>`)は、型の引数に入れる型が決まらないので、プローブを作れず、未検証で残る。HTTP クライアントでは、主要な API の多くがジェネリクスで、未検証の行の割合が大きい。

案: 型の引数に、具体的な型を入れてプローブを作る(`get<String>`、`get<Object?>`)。成り立つかを確かめる点: (1) 戻り値の型が型の引数で決まるとき、流れの照合(引数 → 戻り値)が、具体的な型でも同じ結果になるか。(2) 入れる型を、どう選ぶか(境界があれば境界、なければ `Object?` か `String`)。(3) 具体的な型ごとに結果が変わる行(型で分岐する本体)の扱い。

それまでは、生成器と差分テストの対象外として明示する([../DESIGN-package-models.md](../DESIGN-package-models.md) 6.7 の「対象外として明示する範囲」)。手順書では、「未検証」と、PR の本文に書く。
