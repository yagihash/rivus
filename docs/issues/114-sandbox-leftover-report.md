## 今の状態

`setsid`、二重フォークで、グループを抜けたプロセスは、実行の終わりに止められない。今は「残ったかもしれない」と報告するだけ(`Result.MayHaveLeftProcesses`)。見つける処理を足すなら、列挙して報告するだけ(PID、名前、起動時刻)。rivus は、自分が起動したグループの外のプロセスにシグナルを送らない(事故: 約 120 個の kill)。

## 終わりの条件

見つけ方を調べ(環境の目印は、Apple 署名のプログラムでは見えない)、完全でなければ「確かめられなかった」と報告する。kill は利用者がする。
