## 何が起きるか

モデルの行は、本体のない呼び出しの既定の扱い(受け手と引数が結果に流れる。引数の指す先は不明)を**置き換える**。引数への書き込みや受け手を書き忘れた行は、既定より流れを減らすが、何も言わない(`docs/MODELING.md` の 0 節)。`rivus models coverage` の雛形が、最初の 2 つの版で、`bench/gcp` の 27 件のうち 3 件、2 件を失った(今は直した)。

## あるべき出力

行を足したことで消えた流れ(行がなければ見つかっていた流れ)を、言う検査。= `rivus models compare`(`DESIGN-model-authoring.md` の段 4)の受け入れの形の 1 つ。

## 終わりの条件

`compare`(または同等の検査)が、行を足す前後の finding の差(消えたもの)を出し、消えたものがあれば、その行に理由(`approximate` と理由、または確かめた記録)を求める。
