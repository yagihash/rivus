# #122 Rust: IR の `file` に、std のソースの絶対パス(ツールチェインの場所)が入る

- 補足(種類): 再現性

- 補足(守るもの): まだない(直すときにテスト)

## 何が起きるか

標準ライブラリの関数の IR の `file` に、固定のツールチェインの `lib/rustlib/src/...` の絶対パスが入る。ツールチェインの場所が違う機械(または、`~/.rustup` と Homebrew の keg)の間で、同じコードから出る IR が、この `file` だけ違う。2026-11-22 の確認(`bench/zoo-rust`)で、パスの差だけを丸めると、IR は同一だった。結果(経路、finding)の違いではなく、IR のバイトの比較にだけ影響する。

## 終わりの条件

ツールチェインの下のパスを、場所によらない形(例: `rust-src:` + 相対パス)で書く。または、比べる側が丸める、と決めて文書に書く。
