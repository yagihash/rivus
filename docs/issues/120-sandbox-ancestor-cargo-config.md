# #120 祖先の .cargo/config.toml があると、抽出が止まる(読み取りだけ許す案)

- 状態: **open**(後回しのハードニング。ADR-093)
- 種類: 利用者を止める(閉じる向き)
- 言語: Rust
- ROADMAP の節: 0(Homebrew のインストールの作業の続き)
- 守るもの: まだない(直すときにテストを足す)

## 今の状態

cargo は、対象の上のディレクトリの `.cargo/config.toml` も読み、サンドボックスはそれを読ませないので、何も実行せずに、ファイルの名前を示して止まる。`~/.cargo/config.toml` を持つ利用者は、ホームの下の対象を、サンドボックスの下で抽出できない(回避: そのファイルを一時的に退ける、信頼できるコードなら `-unsafe-host-exec`)。

## 終わりの条件

(a) 祖先の `.cargo/config*` を、名指しで読み取りだけ許す(対象の外の設定が抽出に影響する。`rustc-wrapper` は、実行を許していないので失敗する = 閉じる向き)、(b) フラグで選ぶ。判断は相談役。

## 経緯

- 2026-11-22: macOS のサンドボックスへの切り替え(ADR-093)で、ユーザーが「切り替えを先に、ハードニングは後」と決めた分として、課題に上げた。
