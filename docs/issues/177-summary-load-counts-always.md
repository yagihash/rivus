# 177: `summary` が、読み込みの結果の数を、0 のときも出す

- 状態: **open**
- 種類: サイレントな見逃し(読まなかったものの報告)
- 言語: 全
- ROADMAP の節: 2
- 守るもの: -

今の `summary.unread` は、読めなかったものが 1 つもなければ、フィールドごとない。そのため、「0 件読めなかった」と「数えていない」が、出力から区別できない。F-2([ADR-114](../adr/114-project-is-module-and-path-packages.md) の 7。読み込まれなかった同じ module のパッケージの数を `summary` に出す)と同じ種類で、一緒に扱う。

直す方向: `summary` に、常に、読んだパッケージの数、読んだ関数の数、読まなかったもの(`unread`)の数 0、エラーの数 0 を出す(0 のときも)。フィールドがないことを、「問題なし」と読めないようにする。
