### 6.4 1 パッケージ分の作業の手順書

[MODEL-RUNBOOK.md](../MODEL-RUNBOOK.md)。クラウドのセッションが、リポジトリの中のそれだけを読んで作業できる形にした。要点: 着手の宣言 = 題が固定の形(`feat(model): <言語> <パッケージ> の組み込みモデル`)のドラフトの PR を先に立てる(ブランチ名は `claude/` で始まり、宣言に使えない。判定は、PR の題とマージ済みの PR、main のモデルのファイル。リポジトリのファイルにマークを書かない)、標準の 4 ステップ、PR の本文の形、守ること(GitHub の Issue を使わない、署名つき、自分でマージしない、新しい `@miss` / `@fp` には、番号を取らない課題のファイル `docs/issues/model-<パッケージ>-<名前>.md` への `@ref`)、conflict を避ける置き方(段階 0 の前と後を分けて書いた)。
