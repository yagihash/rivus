## 0. 安全(いつでも最優先)

- **目的**: 解析の対象(攻撃者が制御しうる)が、rivus を動かすホストに何もさせないこと。
- **今の状態**: Rust の信頼しないコードは、隔離のコンテナの中だけで読む([rust-isolation.md](rust-isolation.md))。取得元の既定は crates.io だけ。取得の段階のネットワークの絞り込みは案([DESIGN-fetch-network.md](DESIGN-fetch-network.md))。Go と Dart には、隔離がまだない(PRINCIPLES 8 節)。
- **ユーザーの判断(2026-11-22)**: 取得の段階のネットワークの絞り込みと、Go / Dart の隔離は、しばらくやらない。帰結として、第三者のコードの実行と、新しい第三者のパッケージのまとまった解析は、引き続きしない(観測との突き合わせは、動物園と自前の curated だけで進める)。
- **次の作業**: 制御を外す旗(`-unsafe-host-exec` など)が出力に出ること、`[env]` で IR が空になる件の確認。制御を外す旗(`-unsafe-host-exec` など)が出力に出ること、`[env]` で IR が空になる件の確認。
- **決まり**: Go / Dart の隔離ができるまで、新しい第三者のパッケージをまとめて解析・実行しない。Rust の第三者のコードは、隔離のコンテナの中だけ。
- **終わりの条件**: 3 言語とも、信頼しない入力を隔離の中だけで扱える。
