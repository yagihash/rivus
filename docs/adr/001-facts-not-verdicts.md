# ADR-001: 事実を出し、判定はしない

- 状態: 有効
- 関連: ARCHITECTURE, BRIEF
- 状態の詳細: 非目標の「ビルドの面倒を見ない」は Rust で例外: ADR-042/064; 覆した先・注意: ビルド非目標の例外
- 要旨: 事実を構造化して出す。判定はしない。過大近似は維持、列挙は網羅的に

- **状況:** プライベートコードのファイル跨ぎ taint 解析を無償で行える選択肢がなく、最終的な正誤判定は LLM や人間が行う前提で使う。
- **決定:** rivus は「到達可能性に関する事実を問い合わせるクエリエンジン」であり、安全か危険かは決めない。
  決定論的に確定できる事実だけを構造化して出し、確定できなかった理由を分類して残す。
  過大近似は維持する。**列挙は網羅的に、判定は保留する。**
- **理由:** 完全な精度（経路感度、エイリアス解析の完全性）を追わずに済む。
  LLM に判定させる前提なら、判定に必要な材料を揃える方が投資対効果が高い。
- **帰結:** 非目標: 判定を下すこと、完全な経路感度、シンボリック実行・SMT 連携、完全なエイリアス解析、
  暗黙的フロー（制御依存）の追跡、Dart / Rust フロントエンドの自作、対象言語のビルド・コード生成の面倒を見ること、IDE 統合 / Web UI / SaaS 化。
  「LLM が後で落としてくれるから見逃してよい」とはしない。
