# ADR-012: Dart / Rust は外部ツールチェイン依存

- 状態: 有効
- 関連: extractor README
- 状態の詳細: Rust の既定実行は 064 で隔離
- 要旨: 配布の負担を避け、Dart も外部 SDK 前提

- **状況:** ブリーフは Dart extractor を `dart compile exe` でネイティブ化して `go:embed` で埋め込む想定だった（+20MB 程度）。
  しかし `dart compile exe` はクロスコンパイルが限定的で、OS/arch ごとのバイナリを埋め込むには各環境でのビルドが必要になる。
- **決定:** **Dart extractor も Rust と同じく外部ツールチェイン依存とする。**
  対象プロジェクトを解析したい人は Dart SDK を持っている、という前提を Rust と同じ理屈で置く。
  Go extractor はコアに同梱。`go:embed` による埋め込みは、すべて動いてから検討する後工程の最適化とする。
- **理由:** Phase 4 の負担に配布の問題を上乗せするのは筋が悪い。
- **帰結:** extractor の在り処を解決する層（`Locator`）を挟み、「PATH から探す / 設定で指定されたパス / 埋め込みバイナリを展開」を差し替え可能にする。初期実装は前 2 つ。
  ブリーフ 5.5 節の配布形態は、この ADR に合わせて読み替える。
  将来 wasm 化できれば外部依存を外せる可能性があるが（dart2wasm は WasmGC 要求、wazero は未対応）、後から置き換えられる設計にはしておく。
