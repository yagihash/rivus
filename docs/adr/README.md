# ADR のファイル

ADR(設計判断の記録)は 1 件 1 ファイル。**一覧の表は、手で持たない**。各ファイルの先頭のヘッダから、`make docs-gen` が作る(コミットしない)。ADR を足す PR は、ADR のファイルを足すだけ。`docs/DECISIONS.md` と `docs/ADR-INDEX.md` は触らない(衝突しない)。

## 見方

- ディレクトリの一覧(`ls docs/adr`)が、そのまま索引。ファイル名は `NNN-<内容が分かる名前>.md`(番号 3 桁 + 英小文字・数字・`-` の名前)。
- 表: `make docs-gen WHAT=adr`(標準出力。番号、題、状態、関連、ファイル)。ファイルに書くなら `make docs-gen WHAT=adr OUT=docs/ADR-TABLE.md`(`.gitignore` の対象)。
- 並びは番号順。もとの `DECISIONS.md` では 057 が 056 より前、ADR-027 と 030 の追記は ADR-031 の節の中にあった。ファイルに分けたあとも、その本文は、もとの ADR のファイルの中にある(ADR-031 のファイルに、027 と 030 の追記がある)。

## 足し方

1. 番号は、`docs/adr/` の main の最大の番号 + 1(欠番があってよい)。番号がほかの PR と重なったら、`TestAdrFiles` が落ちる。あとから入る PR が、番号を付け直す(本文の中の `ADR-NNN` も直す)。
2. ファイル名は `<番号>-<短い名前>.md`。名前は英小文字・数字・`-`。
3. 1 行目は `# ADR-NNN: <題>`、その下にヘッダ(次の節)、そのあとに本文(状況 → 決定 → 理由 → 帰結)。
4. `make docs-gen WHAT=adr` で、行が出ることを確かめる。

## ヘッダの形

`# ` の題の行のすぐ下に、`- <キー>: <値>` の行を並べる。

| キー | 内容 |
| --- | --- |
| `状態` | `有効` / `一部覆った` / `覆った`。覆されたときは `一部覆った(→ADR-MMM)` のように、覆した先を書く(複数は `→ADR-040, ADR-075`)。足すときは `有効` |
| `関連` | 関連する文書(例: `ARCHITECTURE 2.1`)。なければ `-` |
| `状態の詳細`(任意) | 覆した先の説明、本文に残る古い記述の注意 |
| `要旨`(任意) | 一言の要旨 |

## 書き換えないこと

ADR は、決めた時点の記録。本文は書き換えない。後の ADR が覆すときは、古い ADR の `状態` の行だけを直す。本文の誤りを直した記録が必要なときは、日付と理由を付けた追記の節で足す(いくつかの ADR にその形がある。[ADR-INDEX.md](../ADR-INDEX.md) の注記)。

[DECISIONS.md](../DECISIONS.md) は、この形の案内。
